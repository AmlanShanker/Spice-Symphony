# 🍽️ Spice Symphony – Restaurant Management Website

**🌐 Live Demo:** https://amlanshanker.github.io/

Spice Symphony is a responsive restaurant management website developed to enhance the fine dining experience by providing customers with an engaging online platform. The website allows users to explore the restaurant, browse menus, reserve tables, make payments, and access important restaurant information through a clean and user-friendly interface.

The project is built using **HTML**, **CSS**, **JavaScript**, and **PHP**, with backend support for reservations, payments, and database connectivity.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/spice-symphony.git
```

### 2. Move the Project

Copy the project folder into your local server directory.

For example:

- **XAMPP:** `htdocs/`
- **WAMP:** `www/`
- **Laragon:** `www/`

### 3. Start the Server

Start the following services:

- Apache
- MySQL

### 4. Configure the Database

Open:

```text
dbCongih1.php
```

Update the database credentials with your local MySQL configuration.

Example:

```php
$host = "localhost";
$username = "root";
$password = "";
$database = "restaurant";
```

### 5. Import the Database

Import the provided SQL file (if available) into MySQL using phpMyAdmin.

### 6. Run the Project

Open your browser and visit:

```text
http://localhost/SpiceSymphony/home1.php
```

or

```text
http://localhost/your-project-folder/home1.php
```
